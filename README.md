# CS 499 Milestone Three: Algorithms and Data Structures
Grazioso Salvare Animal Shelter Dashboard

## Project Overview

This project enhances the Grazioso Salvare animal shelter dashboard by improving the algorithms and data structures used to evaluate and rank rescue candidates. Enhancements include a min-heap ranking algorithm, weighted scoring based on breed, age, and sex, improved candidate selection, and automated testing to verify accuracy and performance.

## Live Dashboard

https://grazioso-salvare-dashboard-milestone.onrender.com

Authentication is required. Login credentials are provided in the zip README.

The dashboard is hosted on Render and connected to MongoDB Atlas.

**Note:** The dashboard may take 1–2 minutes to load if the Render service has been inactive.
